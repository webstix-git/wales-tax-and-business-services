# Wales Tax & Business Services (Next.js)

Faithful Next.js conversion of the static HTML site in `../Wales-Tax-Website`. Layout, content, assets, and interactions are preserved.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

| Original HTML        | Next.js route      |
| -------------------- | ------------------ |
| `index.html`         | `/`                |
| `services.html`      | `/services`        |
| `about-us.html`      | `/about-us`        |
| `our-mission.html`   | `/our-mission`     |
| `meet-the-team.html` | `/meet-the-team`   |
| `contact-us.html`    | `/contact-us`      |
| `thank-you.html`     | `/thank-you`       |
| `site-map.html`      | `/site-map`        |
| `privacy-policy.html`| `/privacy-policy`  |
| `ai-policy.html`     | `/ai-policy`       |
| `ai-readiness.html`  | `/ai-readiness`    |
| `404.html`           | `not-found`        |

Images are served from `public/images` (copied from the HTML site).
